# قفل الروابط (LinkLock)

تطبيق Flutter بيشفّر أي رابط بكلمة سر، وبيطلّع نص مشفّر تقدر تبعته أو تحفظه في أي مكان. محدش يقدر يعرف الرابط إلا بنفس كلمة السر.

## التشغيل

داخل فولدر المشروع:

```bash
flutter create --project-name linklock .   # بيولّد فولدرات android/ios/web (مش بيمسح ملفاتك)
flutter pub get
flutter test                               # اختبارات التشفير
flutter run
```

لو ظهر خطأ `minSdkVersion` وقت بناء الأندرويد، ارفع `minSdk` في `android/app/build.gradle` (جرّب 24).

## إزاي بيشتغل التشفير

- **اشتقاق المفتاح:** PBKDF2-HMAC-SHA256 بـ 200,000 دورة و salt عشوائي (16 بايت).
- **التشفير:** AES-256-GCM مع nonce عشوائي (12 بايت)، وده بيكشف أي تعديل في النص.
- **شكل النص المشفّر:** `LL1.` + base64url لـ `[version | iterations | salt | nonce | ciphertext | tag]`. الـ version والدورات والـ salt متحمية كـ AAD.
- الرابط نفسه بيتشفّر كل مرة بنتيجة مختلفة (salt و nonce عشوائيين).
- التطبيق مش بيخزّن حاجة ومش بيتصل بالإنترنت، كله بيحصل على الجهاز.

## ملاحظات أمان

- قوة الحماية = قوة كلمة السر. استخدم جملة طويلة، مش كلمة قصيرة.
- لو نسيت كلمة السر مفيش أي طريقة لاسترجاع الرابط.
- التشفير بيخبّي محتوى الرابط، لكن طوله التقريبي ممكن يبان.
- بعد فك التشفير، التطبيق بيعرض الرابط كامل ويسألك قبل ما يفتحه، ومش بيفتحه تلقائي.

## هيكل المشروع

```
lib/

  crypto_service.dart  منطق التشفير وفك التشفير
  ui/                  شاشة التشفير وشاشة فك التشفير
test/

```

## أفكار للتطوير

- خزنة محلية للروابط المشفّرة بالبصمة (`local_auth` + `flutter_secure_storage`).
- مسح QR للنص المشفّر.
- فتح النص المشفّر مباشرة من رابط مشاركة (deep link).
